# Hunk

[Hunk](https://github.com/modem-dev/hunk) is a review-first terminal diff viewer for agent-authored changesets.

The package manages `~/.config/hunk/config.toml` and installs the `hunk` command through the host package manager:

- Arch Linux: the prebuilt `hunk-bin` AUR package
- macOS: the Homebrew `hunk` formula

The configured `gruvbox-dark-hard` theme keeps Hunk on a warm, built-in Gruvbox palette. Hunk also provides Everforest, One Dark, Catppuccin, and similar built-in themes; press `t` while reviewing to preview them.
